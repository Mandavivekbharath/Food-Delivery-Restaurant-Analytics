# Food Delivery & Restaurant Analytics

## Project Overview

This project analyzes food delivery order data to identify trends in customer orders, 
restaurant performance, cuisine preferences, payment methods, and order status.

The analysis was performed using Python and Pandas, followed by an interactive Power BI 
dashboard to present key business insights.

## Objectives

- Analyze food delivery orders and customer preferences.
- Identify popular cities, cuisines, and payment methods.
- Analyze order status and restaurant performance.
- Compare restaurant ratings and average order amounts.
- Create an interactive Power BI dashboard for business insights.

## Data Analysis

The dataset contains 2,000 food delivery transactions. Python and Pandas were used for 
data cleaning, exploratory analysis, and aggregation of key metrics.

The analysis includes:
- Orders by city
- Orders by cuisine
- Order status distribution
- Payment method analysis
- Restaurant customer ratings
- Average order amount by restaurant

## Power BI Dashboard

An interactive dashboard was created in Power BI to visualize the analyzed data through 
KPIs, charts, and business-focused visualizations.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI

## Key Insights

- Analyzed order distribution across different cities and cuisines.
- Compared delivered, cancelled, and delayed orders.
- Identified payment method preferences.
- Compared restaurant ratings and average order amounts.
- Presented the findings through an interactive Power BI dashboard.

## Project Workflow

Python Data Analysis → Data Aggregation → CSV Export → Power BI → Dashboard
